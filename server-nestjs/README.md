# Code A2Z - NestJS Backend

This directory contains the new NestJS + TypeScript backend for Code A2Z.

This is the initial backend setup. The existing Express backend
remains unchanged.

## Prerequisites

- Node.js (v24.15+ recommended)
- npm

## Installation

From the repository root:

```bash
cd server-nestjs
npm install
```

## Development

```bash
npm run start:dev
```

The server runs at http://localhost:3000 by default.

## Build

```bash
npm run build
```

## Tests

```bash
npm run test
```

## Current Scope

- NestJS + TypeScript project setup
- Basic controller and service
- Development and build configuration

Database integration, Express migration, and organization onboarding
will be implemented separately.
